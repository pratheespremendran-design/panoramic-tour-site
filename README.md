# Panoramic Tour — Sri Lanka

White, motion-rich single-page site for Panoramic Tour & Travels (Pvt) Ltd.
Live: https://pratheespremendran-design.github.io/panoramic-tour-site/

- `index.html`, `css/site.css`, `js/site.js` — page, styles, interactions (GSAP + ScrollTrigger + Lenis, self-hosted).
- Images and fonts ship as a base64 tar bundle in `bundle/` and are unpacked and checksum-verified by `.github/workflows/pages.yml`, which publishes to the `gh-pages` branch.
- The enquiry form stores nothing: it opens a prefilled WhatsApp message (or an email draft).
